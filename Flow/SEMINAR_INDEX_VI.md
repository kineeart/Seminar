## 🎬 Cách Sử Dụng Tệp .drawio

### Bước 1: Tải Draw.io
```
https://draw.io → Mở Trình Chỉnh Sửa
```

### Bước 2: Nhập Tệp
```
File → Open → Chọn *.drawio
hoặc
Kéo & Thả *.drawio vào draw.io
```

### Bước 3: Chỉnh Sửa / Xuất
```
Chỉnh Sửa Hình Dạng, Thiết Lập Màu
Xuất → PNG / SVG → Sử Dụng Trong Slide
```

### Tệp Để Sử Dụng

| Tệp | Sử Dụng Cho |
|-----|----------|
| SYSTEM_ARCHITECTURE_DIAGRAM.drawio | Slide tiêu đề, tổng quan hệ thống |
| DATA_FLOW_DIAGRAM.drawio | Giải thích luồng dữ liệu |
